# Recordings

Sample ENACT session recordings (JSONL, one frame per line) for offline replay
with `player.py` — no robot or camera needed.

Included here:

- `r1g1.jsonl.txt` (~1.2 MB) — short sample session
- `r2g1.jsonl.txt` (~1 MB) — short sample session
